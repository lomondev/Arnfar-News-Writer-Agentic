# VAT ຂາເຂົ້າ, VAT ຂາອອກ ແລະ VAT ຫັກໄວ້ — ເຂົ້າໃຈໃນ 3 ນາທີ

## POST (copy from here ↓)

🧾💡 ເຮັດບັນຊີແລ້ວສັບສົນເລື່ອງ VAT ບໍ? ມື້ນີ້ Arnfar ອະທິບາຍ VAT ຂາເຂົ້າ, VAT ຂາອອກ ແລະ VAT ຫັກໄວ້ ໃຫ້ເຂົ້າໃຈງ່າຍໆ! 📊🇱🇦

ສະບາຍດີຊາວ Arnfar! ສຳລັບເຈົ້າຂອງທຸລະກິດ ແລະ ນັກບັນຊີລາວ, ການເຂົ້າໃຈ VAT (ອາກອນມູນຄ່າເພີ່ມ) ໃຫ້ຖືກຕ້ອງ ຊ່ວຍໃຫ້ຍື່ນອາກອນບໍ່ຜິດ ແລະ ບໍ່ເສຍຄ່າປັບໃໝ. ອັດຕາ VAT ມາດຕະຖານຂອງ ສປປ ລາວ ປັດຈຸບັນ (ປີ 2026) ແມ່ນ 10% (ບາງລາຍການໄດ້ອັດຕາຫຼຸດ 5% ຫຼື 0%).

🔍 3 ຄຳສັບທີ່ຕ້ອງແຍກໃຫ້ອອກ

1️⃣ VAT ຂາເຂົ້າ (Input VAT) — ອາກອນທີ່ເຮົາ "ຈ່າຍ" ຕອນຊື້ສິນຄ້າ/ບໍລິການເຂົ້າມາ. ບັນທຶກເປັນ "ຊັບສິນ" (ສິ່ງທີ່ລັດຄ້າງເຮົາ). ຕ້ອງມີໃບເກັບເງິນ VAT ຖືກຕ້ອງຈຶ່ງນຳມາຫັກໄດ້.

2️⃣ VAT ຂາອອກ (Output VAT) — ອາກອນທີ່ເຮົາ "ເກັບ" ຈາກລູກຄ້າຕອນຂາຍ. ບັນທຶກເປັນ "ໜີ້ສິນ" (ສິ່ງທີ່ເຮົາຄ້າງລັດ).

3️⃣ VAT ຫັກໄວ້ (Withholding VAT) — ເມື່ອຈ່າຍຄ່າບໍລິການໃຫ້ຜູ້ໃຫ້ບໍລິການຢູ່ຕ່າງປະເທດ (ເຊັ່ນ: ໂຄສະນາ Facebook, software ຕ່າງປະເທດ), ຜູ້ຊື້ຢູ່ລາວມີໜ້າທີ່ "ຫັກ VAT 10% ໄວ້" ແລ້ວນຳສົ່ງໃຫ້ລັດແທນ.

💰 ຄິດໄລ່ VAT ທີ່ຕ້ອງຈ່າຍແນວໃດ?
ໃຊ້ວິທີ "ຫັກກັນ" (credit method):
• VAT ທີ່ຕ້ອງຈ່າຍລັດ = VAT ຂາອອກ − VAT ຂາເຂົ້າ

ຕົວຢ່າງງ່າຍໆ:
• ຊື້ສິນຄ້າ 1,000,000 ກີບ → ຈ່າຍ VAT ຂາເຂົ້າ 10% = 100,000 ກີບ
• ຂາຍສິນຄ້າ 1,500,000 ກີບ → ເກັບ VAT ຂາອອກ 10% = 150,000 ກີບ
• VAT ຕ້ອງຈ່າຍລັດ = 150,000 − 100,000 = 50,000 ກີບ

✅ ຂໍ້ຄວນຮູ້ / ເຮັດໃຫ້ຖືກ
✅ ເກັບໃບເກັບເງິນ VAT ຂາເຂົ້າໃຫ້ຄົບ — ບໍ່ມີໃບ = ຫັກ VAT ຂາເຂົ້າບໍ່ໄດ້
✅ VAT ຂາເຂົ້າ = ຊັບສິນ, VAT ຂາອອກ = ໜີ້ສິນ — ຢ່າບັນທຶກສະຫຼັບກັນ
✅ ຈ່າຍຄ່າບໍລິການຕ່າງປະເທດ ຢ່າລືມຫັກ VAT 10% ນຳສົ່ງລັດ
✅ ຍື່ນ ແລະ ຊຳລະ VAT ໃຫ້ທັນກຳນົດແຕ່ລະເດືອນ

❌ ຂໍ້ຄວນລະວັງ
❌ ຊື້ຈາກຜູ້ຂາຍທີ່ບໍ່ໄດ້ຈົດທະບຽນ VAT — ອາດຫັກ VAT ຂາເຂົ້າບໍ່ໄດ້ ຖ້າບໍ່ຕິດຕໍ່ພະແນກສ່ວຍສາອາກອນ
❌ ລືມຫັກ VAT ຫັກໄວ້ ຈາກຄູ່ຄ້າຕ່າງປະເທດ — ຄວາມຮັບຜິດຊອບຕົກໃສ່ຜູ້ຊື້ຢູ່ລາວ
❌ ຄິດ VAT ຜິດອັດຕາ (ບາງລາຍການ 0%/5% ບໍ່ແມ່ນ 10% ໝົດ)
❌ ຍື່ນຊ້າ = ຄ່າປັບໃໝ ແລະ ດອກເບ້ຍ

📌 ສະຫຼຸບ: VAT ຂາເຂົ້າ ຄື VAT ທີ່ຈ່າຍ, VAT ຂາອອກ ຄື VAT ທີ່ເກັບ, ສ່ວນຕ່າງຄືອາກອນທີ່ຕ້ອງນຳສົ່ງລັດ — ແລະ ຢ່າລືມ VAT ຫັກໄວ້ ຕອນຈ່າຍໃຫ້ຕ່າງປະເທດ.

👉 ທຸລະກິດຂອງທ່ານຈັດການ VAT ດ້ວຍມື ຫຼື ໃຊ້ລະບົບບັນຊີ? ຄອມເມັນມາລົມກັນ! 💬
