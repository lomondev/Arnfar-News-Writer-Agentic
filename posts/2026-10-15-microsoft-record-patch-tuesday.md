# Microsoft ອອກແພັດຄວາມປອດໄພໃຫຍ່ທີ່ສຸດ — ແກ້ຊ່ອງໂຫວ່ 1,413 ຈຸດ

## POST (copy from here ↓)

🛡️ Microsoft ອອກແພັດຄວາມປອດໄພໃຫຍ່ທີ່ສຸດໃນປະຫວັດສາດ — ແກ້ຊ່ອງໂຫວ່ 1,413 ຈຸດ ແລະ ມີ 1 ຈຸດທີ່ຖືກແຮັກເກີໂຈມຕີແລ້ວ! ອັບເດດ Windows ດ່ວນ!

ວັນທີ 13 ຕຸລາ 2026, Microsoft ໄດ້ປ່ອຍອັບເດດຄວາມປອດໄພປະຈຳເດືອນ (Patch Tuesday) ທີ່ແກ້ໄຂຊ່ອງໂຫວ່ຫຼາຍເຖິງ 1,413 ຈຸດ — ຫຼາຍທີ່ສຸດເທົ່າທີ່ເຄີຍມີມາ (ເດືອນກັນຍາ ມີປະມານ 970 ຈຸດ). ອີງຕາມ CrowdStrike, ໃນນັ້ນມີປະມານ 75 ຈຸດ ທີ່ຢູ່ໃນລະດັບຮ້າຍແຮງ (Critical).

ຈຸດທີ່ອັນຕະລາຍທີ່ສຸດ ແມ່ນ CVE-2026-96951 (ຄະແນນ 8.8/10) — ຊ່ອງໂຫວ່ໃນ Windows Shell ທີ່ຖືກນຳໃຊ້ໂຈມຕີແລ້ວ. ມັນຂ້າມລະບົບ Mark of the Web ທີ່ປົກກະຕິຈະເຕືອນເວລາເປີດໄຟລ໌ທີ່ດາວໂຫຼດມາຈາກອິນເຕີເນັດ, ເຮັດໃຫ້ຄຳເຕືອນຂອງ SmartScreen ແລະ Protected View ໃນ Office ບໍ່ເຮັດວຽກ. ແຮັກເກີພຽງແຕ່ສົ່ງໄຟລ໌ ຫຼື ລິ້ງ ຜ່ານອີເມວ ຫຼື ແຊັດ ແລ້ວລໍຖ້າໃຫ້ຜູ້ໃຊ້ກົດເປີດ. ອົງການ CISA ຂອງສະຫະລັດ ສັ່ງໃຫ້ໜ່ວຍງານລັດແກ້ໄຂໃຫ້ແລ້ວພາຍໃນວັນທີ 16 ຕຸລາ.

ຈຸດສຳຄັນອື່ນໆ:
• Outlook ມີຊ່ອງໂຫວ່ຮ້າຍແຮງ 5 ຈຸດ (ຄະແນນ 9.8) — ບາງຈຸດຖືກໂຈມຕີໄດ້ ພຽງແຕ່ເປີດເບິ່ງອີເມວໃນ Reading Pane ໂດຍບໍ່ຕ້ອງກົດຫຍັງ
• Word, Excel, PowerPoint ແລະ Visio ມີຊ່ອງໂຫວ່ຮ້າຍແຮງ 20 ຈຸດ ທີ່ອາດຖືກໃຊ້ຣັນໂຄດອັນຕະລາຍ
• ແບ່ງຕາມປະເພດ: ຍົກລະດັບສິດ 677 ຈຸດ, ຣັນໂຄດຈາກທາງໄກ 317 ຈຸດ, ຮົ່ວໄຫຼຂໍ້ມູນ 254 ຈຸດ
• Windows 11 ລຸ້ນ 24H2 (Home ແລະ Pro) ໝົດການຊັບພອດແລ້ວ ຕັ້ງແຕ່ວັນທີ 13 ຕຸລາ 2026 — ຕ້ອງອັບເກຣດເປັນລຸ້ນໃໝ່ກວ່າ ຈຶ່ງຈະໄດ້ຮັບອັບເດດຄວາມປອດໄພຕໍ່

ເປັນຫຍັງຈຶ່ງຫຼາຍຂະໜາດນີ້? ຕັ້ງແຕ່ຕົ້ນປີ 2026, Microsoft ເລີ່ມໃຊ້ AI ຊອກຫາຊ່ອງໂຫວ່ໃນໂຄດຂອງຕົນເອງ. ຮອງປະທານຝ່າຍວິສະວະກຳ Tom Gallagher ເຄີຍກ່າວວ່າ AI ຊ່ວຍໃຫ້ຊອກບັກໄດ້ໄວ ແລະ ຫຼາຍກວ່າທີ່ເຄີຍມີມາ, ແລະ ອັບເດດຂະໜາດໃຫຍ່ແບບນີ້ ອາດກາຍເປັນເລື່ອງປົກກະຕິ.

ສຳລັບລາວ: ຫ້ອງການ, ທະນາຄານ, ຮ້ານຄ້າ ແລະ ຜູ້ໃຊ້ທົ່ວໄປ ສ່ວນໃຫຍ່ໃຊ້ Windows ແລະ Office. ຖ້າບໍ່ອັບເດດ, ພຽງແຕ່ເປີດໄຟລ໌ແນບໃນອີເມວ ກໍອາດຖືກແຮັກ ຫຼື ຕິດ ransomware ໄດ້.

ວິທີປ້ອງກັນ:
• ໄປທີ່ Start > Settings > Windows Update > Check for updates ແລ້ວຕິດຕັ້ງໃຫ້ຄົບ ແລະ ຣີສະຕາດເຄື່ອງ
• ກວດຄືນອີກຄັ້ງ ຈົນຂຶ້ນວ່າ "You're up to date"
• ອັບເດດ Microsoft Office ແລະ Outlook ນຳ
• ຢ່າເປີດໄຟລ໌ແນບ ຫຼື ລິ້ງ ທີ່ບໍ່ຮູ້ທີ່ມາ ເຖິງວ່າຈະມາຈາກຄົນຮູ້ຈັກກໍຕາມ
• ສຳລັບອົງກອນ: ອັບເດດ CVE-2026-96951 ແລະ Outlook ກ່ອນ

📌 ສະຫຼຸບ: ອັບເດດ Windows ມື້ນີ້ — ໃຊ້ເວລາບໍ່ດົນ ແຕ່ປ້ອງກັນຄວາມເສຍຫາຍໄດ້ຫຼາຍ.
👉 ທ່ານອັບເດດ Windows ຄັ້ງລ່າສຸດເມື່ອໃດ? 💬
