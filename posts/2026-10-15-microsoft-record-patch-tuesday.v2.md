# Microsoft ແກ້ຊ່ອງໂຫວ່ 1,413 ຈຸດ (v2 — human voice)

## POST (copy from here ↓)

ອາທິດນີ້ ຖ້າ Windows ຂຶ້ນໃຫ້ອັບເດດ ຢ່າກົດເລື່ອນໄວ້. Microsoft ຫາກໍແກ້ຊ່ອງໂຫວ່ 1,413 ຈຸດໃນຮອບດຽວ, ແລະ ມີຢູ່ຈຸດໜຶ່ງທີ່ແຮັກເກີກຳລັງໃຊ້ໂຈມຕີແທ້ແລ້ວ.

ນີ້ແມ່ນອັບເດດປະຈຳເດືອນ (Patch Tuesday) ທີ່ໃຫຍ່ທີ່ສຸດເທົ່າທີ່ເຄີຍມີ, ອອກວັນທີ 13 ຕຸລາ 2026. ເດືອນກັນຍາມີພຽງປະມານ 970 ຈຸດ. ໃນຮອບນີ້ ມີປະມານ 75 ຈຸດຢູ່ໃນລະດັບຮ້າຍແຮງ (Critical), ອີງຕາມ CrowdStrike.

ຈຸດທີ່ຕ້ອງລະວັງທີ່ສຸດແມ່ນ CVE-2026-96951 (ຄະແນນ 8.8 ຈາກ 10). ມັນເຮັດໃຫ້ຄຳເຕືອນທີ່ Windows ສະແດງເວລາເປີດໄຟລ໌ຈາກອິນເຕີເນັດ ບໍ່ຂຶ້ນ. ແຮັກເກີພຽງແຕ່ສົ່ງໄຟລ໌ ຫຼື ລິ້ງ ມາທາງອີເມວ ຫຼື ແຊັດ, ແລ້ວລໍຖ້າໃຫ້ຜູ້ໃຊ້ກົດເປີດ. ອົງການ CISA ຂອງສະຫະລັດ ສັ່ງໃຫ້ໜ່ວຍງານລັດແກ້ໃຫ້ແລ້ວພາຍໃນວັນທີ 16 ຕຸລາ.

Outlook ກໍມີບັນຫາໜັກ. 5 ຈຸດໄດ້ຄະແນນ 9.8, ແລະ ບາງຈຸດຖືກໂຈມຕີໄດ້ ພຽງແຕ່ເປີດເບິ່ງອີເມວໃນ Reading Pane. ສ່ວນ Word, Excel, PowerPoint ແລະ Visio ມີອີກ 20 ຈຸດທີ່ຮ້າຍແຮງ.

ເປັນຫຍັງເທື່ອນີ້ຈຶ່ງຫຼາຍຂະໜາດນີ້? Microsoft ເລີ່ມໃຊ້ AI ຊອກຊ່ອງໂຫວ່ໃນໂຄດຂອງຕົນເອງຕັ້ງແຕ່ຕົ້ນປີ, ແລະ ບອກວ່າອັບເດດຂະໜາດໃຫຍ່ແບບນີ້ອາດກາຍເປັນເລື່ອງປົກກະຕິ.

ສຳລັບຫ້ອງການ ແລະ ຮ້ານຄ້າໃນລາວ ທີ່ໃຊ້ Windows ແລະ Office ເກືອບທຸກເຄື່ອງ, ສິ່ງທີ່ຄວນເຮັດມື້ນີ້:
1. ເປີດ Settings > Windows Update ແລ້ວກົດ Check for updates
2. ຕິດຕັ້ງໃຫ້ຄົບ, ຣີສະຕາດ, ແລ້ວກວດຄືນຈົນຂຶ້ນວ່າ "You're up to date"
3. ອັບເດດ Office ແລະ Outlook ນຳ
4. ໄຟລ໌ແນບ ຫຼື ລິ້ງ ທີ່ບໍ່ໄດ້ຄາດໄວ້ ຢ່າເປີດກ່ອນສອບຖາມຜູ້ສົ່ງ

ຖ້າເຄື່ອງຍັງໃຊ້ Windows 11 ລຸ້ນ 24H2 (Home ຫຼື Pro), ລຸ້ນນີ້ໝົດການຊັບພອດແລ້ວຕັ້ງແຕ່ 13 ຕຸລາ. ຄວນອັບເກຣດ ເພື່ອໃຫ້ໄດ້ຮັບອັບເດດຄວາມປອດໄພຕໍ່.
