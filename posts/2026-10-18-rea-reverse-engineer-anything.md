# REA: ເຄື່ອງມືໃຫ້ AI ຊ່ວຍ Reverse Engineer ໂປຣແກຣມ

## POST (copy from here ↓)

ໂປຣເຈັກໃໝ່ທີ່ຮ້ອນທີ່ສຸດເທິງ GitHub ເດືອນນີ້ ບໍ່ແມ່ນແອັບ AI ແຕ່ເປັນເຄື່ອງມື Reverse Engineering.

REA (Reverse Engineer Anything) ເປັນໂປຣແກຣມ open source ລິຂະສິດ MIT ທີ່ເຊື່ອມ AI agent ເຊັ່ນ Claude Code, Codex, Cursor ແລະ Gemini CLI ເຂົ້າກັບເຄື່ອງມືແກະໂປຣແກຣມທີ່ນັກຄວາມປອດໄພໃຊ້ຢູ່ແລ້ວ ຄື Ghidra, IDA Pro ແລະ Hopper ຜ່ານ MCP. ແທນທີ່ຈະນັ່ງອ່ານ assembly ເອງເປັນມື້, ທ່ານສາມາດຖາມ AI ໃຫ້ໄລ່ໂຄດ, ສະຫຼຸບຟັງຊັນ ແລະ ຂໍຫຼັກຖານເພີ່ມໄດ້.

ສິ່ງທີ່ມັນວິເຄາະໄດ້:
• ໄຟລ໌ binary: pseudocode, assembly, strings ແລະ ການເອີ້ນຟັງຊັນ
• ແອັບ Electron ແລະ JavaScript: ໂມດູນ, route ແລະ IPC
• .NET, Android APK, firmware, WebAssembly ແລະ ໂປຣແກຣມ Go

ໂປຣເຈັກນີ້ມີດາວເທິງ GitHub ຫຼາຍກວ່າ 300,000 ດວງແລ້ວ. ຕິດຕັ້ງດ້ວຍຄຳສັ່ງ npx rea-agents setup ແລະ ຕ້ອງໃຊ້ Node.js 22 ຂຶ້ນໄປ.

ຂໍ້ຄວນລະວັງ: REA ແລ່ນໃນເຄື່ອງ ແຕ່ຜົນການວິເຄາະຖືກສົ່ງໃຫ້ AI ຈຶ່ງຢູ່ພາຍໃຕ້ນະໂຍບາຍຂໍ້ມູນຂອງຜູ້ໃຫ້ບໍລິການ AI. ແລະ ການແກະໂປຣແກຣມຂອງຄົນອື່ນໂດຍບໍ່ໄດ້ຮັບອະນຸຍາດ ອາດຜິດເງື່ອນໄຂລິຂະສິດ ຫຼື ກົດໝາຍ. ໃຊ້ກັບງານທີ່ທ່ານມີສິດເທົ່ານັ້ນ ເຊັ່ນ ວິເຄາະ malware, ກວດແອັບຂອງບໍລິສັດຕົນເອງ ຫຼື ກວດຊອບແວທີ່ຈະນຳມາໃຊ້.

ສຳລັບບໍລິສັດຊອບແວໃນລາວ ນີ້ຄືສັນຍານເຕືອນ: ຖ້າ AI ແກະແອັບໄດ້ງ່າຍຂະໜາດນີ້, API key ຫຼື ລະຫັດລັບທີ່ຝັງໄວ້ໃນແອັບມືຖື ຫຼື ແອັບ Electron ກໍຖືກພົບໄດ້ງ່າຍຄືກັນ. ຄວນຍ້າຍສິ່ງເຫຼົ່ານັ້ນໄປໄວ້ຝັ່ງເຊີບເວີ.

ທີມທ່ານເຄີຍໃຊ້ Ghidra ຫຼື IDA ກວດແອັບຂອງຕົນເອງແລ້ວບໍ່?

ຕິດຕາມເພຈ Arnfar ໄວ້ ເພື່ອຮູ້ທັນເຄື່ອງມື AI ແລະ ຄວາມປອດໄພ.
