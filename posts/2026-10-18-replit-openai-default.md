# Replit ປ່ຽນໂມເດວຫຼັກຈາກ Claude ໄປໃຊ້ OpenAI

## POST (copy from here ↓)

Replit ແພລດຟອມຂຽນໂຄດດ້ວຍ AI ປ່ຽນໂມເດວຫຼັກຂອງ Replit Agent ຈາກ Claude ຂອງ Anthropic ໄປເປັນ ChatGPT ຂອງ OpenAI.

Amjad Masad, CEO ຂອງ Replit, ປະກາດເທິງເວທີ TechCrunch Disrupt ໃນວັນທີ 16 ຕຸລາ ວ່າເປັນການຕັດສິນໃຈຈາກ "ຕົ້ນທຶນ, ການເປັນພາດເນີ ແລະ ປະສິດທິພາບ". ລາວບອກວ່າ ຕອນນີ້ ChatGPT ເຮັດໄດ້ດີກວ່າ ໂດຍອີງຕາມຜົນທົດສອບຂອງ Replit ເອງ.

ຫຼັງຈາກນັ້ນ Masad ອະທິບາຍເພີ່ມວ່າ Replit ບໍ່ໄດ້ຕັດ Claude ອອກ:
• OpenAI ເປັນໂມເດວເລີ່ມຕົ້ນ (default) ຂອງ Replit Agent ແລ້ວ
• ຜູ້ໃຊ້ຍັງເລືອກໃຊ້ Claude ຫຼື ໂມເດວອື່ນໄດ້ຄືເກົ່າ
• Replit ຍັງເປັນແພລດຟອມທີ່ບໍ່ຜູກມັດກັບໂມເດວໃດໜຶ່ງ

ເລື່ອງນີ້ສຳຄັນ ເພາະຜູ້ໃຊ້ສ່ວນໃຫຍ່ບໍ່ປ່ຽນ default. Masad ບອກວ່າ Replit ເຄີຍເປັນລູກຄ້າ 5 ອັນດັບທຳອິດຂອງ Anthropic. ແຕ່ກໍມີຄົນໃນທີ່ບອກ TechCrunch ວ່າ ຄວາມຮ່ວມມືກັບ Anthropic ຍັງບໍ່ທັນສິ້ນສຸດ, ແລະ ທາງ Anthropic ຍັງບໍ່ໄດ້ໃຫ້ຄວາມເຫັນ.

ສຳລັບ dev ໃນລາວທີ່ໃຊ້ Replit ຢູ່, ຜົນງານຂອງ Agent ອາດປ່ຽນໄປຕາມໂມເດວ. ຖ້າເຄີຍຊິນກັບ Claude ໃຫ້ກວດການຕັ້ງຄ່າໂມເດວໃນໂປຣເຈັກ ແລະ ລອງທຽບຜົນເອງກ່ອນ.

ຕອນນີ້ທ່ານໃຊ້ AI ໂຕໃດຊ່ວຍຂຽນໂຄດ: Claude, ChatGPT ຫຼື Gemini?

ຕິດຕາມ Arnfar ໄວ້ ມີຂ່າວ AI ໃໝ່ໆທຸກມື້.
