# ຄວາມຮູ້ພາສີ: Input VAT vs Output VAT — ບໍລິຫານອາກອນໃຫ້ເປັນ

## POST (copy from here ↓)

💸📊 Input VAT ກັບ Output VAT ຕ່າງກັນແນວໃດ? ເຈົ້າຂອງທຸລະກິດຫຼາຍຄົນຍັງສັບສົນ — ເຂົ້າໃຈ 2 ຄຳນີ້ ທ່ານອາດຈ່າຍພາສີໜ້ອຍລົງຢ່າງຖືກກົດໝາຍ! 🇱🇦

ສະບາຍດີຊາວ Arnfar! ມື້ນີ້ເຮົາມາເສີມຄວາມຮູ້ເລື່ອງການບໍລິຫານພາສີ (Tax Management) ທີ່ເຈົ້າຂອງທຸລະກິດລາວທຸກຄົນຄວນຮູ້ — ອາກອນມູນຄ່າເພີ່ມ (VAT) ຂອງລາວ ປັດຈຸບັນເກັບໃນອັດຕາ 10% ແລະ ບໍລິສັດທີ່ຈົດທະບຽນ ແລະ ມີເລກປະຈຳຕົວຜູ້ເສຍອາກອນ (TIN) ຈະເຂົ້າລະບົບ VAT ໂດຍອັດຕະໂນມັດ (ຍົກເວັ້ນວິສາຫະກິດຈຸນລະພາກ).

🔍 Input VAT ແລະ Output VAT ແມ່ນຫຍັງ?
• Input VAT (ອາກອນຊື້ເຂົ້າ) — VAT 10% ທີ່ທ່ານຈ່າຍ ຕອນຊື້ສິນຄ້າ, ວັດຖຸດິບ ຫຼື ບໍລິການເຂົ້າມາໃຊ້ໃນທຸລະກິດ
• Output VAT (ອາກອນຂາຍອອກ) — VAT 10% ທີ່ທ່ານເກັບຈາກລູກຄ້າ ຕອນຂາຍສິນຄ້າ ຫຼື ບໍລິການອອກໄປ
• ສູດຄິດໄລ່: VAT ທີ່ຕ້ອງມອບໃຫ້ລັດ = Output VAT − Input VAT (ອີງຕາມ PwC ວິທີນີ້ເອີ້ນວ່າ Credit Method)

ຕົວຢ່າງງ່າຍໆ: ເດືອນນີ້ຮ້ານຂອງທ່ານຊື້ວັດຖຸດິບ 100,000,000 ກີບ → ຈ່າຍ Input VAT 10,000,000 ກີບ. ຂາຍສິນຄ້າໄດ້ 150,000,000 ກີບ → ເກັບ Output VAT ຈາກລູກຄ້າ 15,000,000 ກີບ. ສະນັ້ນ ທ່ານມອບໃຫ້ລັດພຽງ 15,000,000 − 10,000,000 = 5,000,000 ກີບເທົ່ານັ້ນ — ບໍ່ແມ່ນ 15 ລ້ານເຕັມ!

ຈຸດສຳຄັນທີ່ຫຼາຍຄົນພາດ:
• Input VAT ຂໍຫັກໄດ້ພາຍໃນ 3 ເດືອນ ນັບຈາກມື້ເກີດລາຍຈ່າຍ
• ທຸລະກິດໃນລະບົບຕ້ອງຍື່ນ ແລະ ມອບ VAT ເປັນລາຍເດືອນ
• ສົ່ງອອກສິນຄ້າ = ອັດຕາ 0% ແລະ Input VAT ທີ່ກ່ຽວຂ້ອງອາດຂໍຄືນໄດ້
• ສິນຄ້າກະສິກຳບໍ່ແປຮູບ, ການສຶກສາ, ການແພດ, ການເງິນ = ຍົກເວັ້ນ VAT

✅ ຂໍ້ດີ ຂອງການບໍລິຫານ VAT ຢ່າງຖືກຕ້ອງ
✅ ຈ່າຍພາສີຕາມຕົວຈິງ — ຫັກ Input VAT ໄດ້ເຕັມສ່ວນ ບໍ່ຈ່າຍຊ້ຳຊ້ອນ
✅ ໃບເກັບເງິນ VAT ຄົບຖ້ວນ = ບັນຊີໂປ່ງໃສ ເຮັດວຽກກັບທະນາຄານ ແລະ ຄູ່ຄ້າໃຫຍ່ງ່າຍຂຶ້ນ
✅ ຜູ້ສົ່ງອອກໄດ້ປະໂຫຍດສອງຕໍ່ — ຂາຍອັດຕາ 0% ແລະ ຍັງຂໍຄືນ Input VAT ໄດ້

❌ ຂໍ້ເສຍ / ສິ່ງທີ່ຕ້ອງລະວັງ
❌ ຂໍຫັກຊ້າເກີນ 3 ເດືອນ = ເສຍສິດຫັກ Input VAT ນັ້ນຖາວອນ
❌ ຊື້ຈາກຜູ້ຂາຍທີ່ບໍ່ຢູ່ໃນລະບົບ VAT ຫຼື ບໍ່ມີໃບເກັບເງິນຖືກຕ້ອງ — ຕ້ອງປະສານສ່ວຍສາອາກອນກ່ອນ ຈຶ່ງນຳມາຫັກໄດ້
❌ ໃຊ້ບໍລິການຈາກຕ່າງປະເທດ ຢ່າລືມໜ້າທີ່ຫັກ VAT 10% ມອບແທນຜູ້ໃຫ້ບໍລິການ (Withholding VAT)

📌 ສະຫຼຸບ: VAT ທີ່ມອບຕົວຈິງ = Output VAT − Input VAT — ພຽງເກັບໃບເກັບເງິນທຸກໃບ, ຫັກໃຫ້ທັນ 3 ເດືອນ ແລະ ຍື່ນທຸກເດືອນ ທຸລະກິດຂອງທ່ານກໍບໍລິຫານພາສີໄດ້ຄືມືອາຊີບ!

👉 ທຸລະກິດຂອງທ່ານເຄີຍພາດບໍ່ໄດ້ຫັກ Input VAT ບໍ? ມາແລກປ່ຽນປະສົບການກັນ! 💬
