# DeepSeek ປ່ອຍ V4.1-Flash-1017 ໄວຂຶ້ນ ຕອບສັ້ນລົງ ເກັ່ງໂຄດຂຶ້ນ

## POST (copy from here ↓)

DeepSeek ອັບເດດໂມເດວ V4.1-Flash ເປັນເວີຊັນ 1017 ເມື່ອວັນທີ 17 ຕຸລາ. ໃຊ້ໄດ້ແລ້ວທັງໃນເວັບ, ແອັບ ແລະ API.

DeepSeek ບອກວ່າເວີຊັນນີ້ເກັ່ງຂຶ້ນ, ເຮັດວຽກແລ້ວໄວຂຶ້ນ ແລະ ຕອບສັ້ນລົງ ເຊິ່ງໝາຍເຖິງຄ່າໃຊ້ຈ່າຍຕໍ່ວຽກທີ່ຖືກລົງນຳ.

ຕົວເລກຈາກ DeepSeek ເອງ:
• DeepSWE (ວັດການແກ້ບັນຫາໂຄດ) ໄດ້ 77.0 ສູງກວ່າເວີຊັນກ່ອນ (74.2) ແລະ ສູງກວ່າ Claude Opus 5 (74.0)
• Terminal-Bench ຂຶ້ນຈາກ 31.2 ເປັນ 42.3 ແຕ່ຍັງຕ່ຳກວ່າ Claude Opus 5 (51.8)
• ລາຄາ API ຊ່ວງປົກກະຕິ $0.30 ຕໍ່ 1 ລ້ານ token ຂາເຂົ້າ ແລະ $1.20 ຂາອອກ, ນອກເວລາເຄິ່ງລາຄາ
• ເປີດ weights ໃຫ້ດາວໂຫຼດໃນ Hugging Face

ອີກຢ່າງທີ່ໜ້າສົນໃຈ: DeepSeek ເປີດ Search ແລະ Fetch API ໃຫ້ທຸກຄົນໃຊ້ ໂດຍໃຊ້ search engine ຂອງຕົນເອງ. ລາຄາ $0.75 ຕໍ່ 1,000 ຄັ້ງ ແລະ ໃຊ້ຜ່ານ Claude Code ຫຼື Codex ໄດ້ຟຣີຮອດທ້າຍເດືອນນີ້.

ໝາຍເຫດ: ຄະແນນທັງໝົດມາຈາກ DeepSeek ເອງ ຍັງບໍ່ມີການທົດສອບຈາກພາຍນອກ. ໃນບາງການທົດສອບ Claude Opus 5 ຍັງນຳໜ້າຢູ່.

ສຳລັບທີມ dev ໃນລາວທີ່ຢາກໃຊ້ AI ຊ່ວຍຂຽນໂຄດ ແຕ່ຫ່ວງເລື່ອງຄ່າ API, ນີ້ແມ່ນທາງເລືອກທີ່ຄວນທົດລອງ.
